VHR Dashboard

Lancer en local sur votre ordinateur

Informations :

Téléchargez l'installateur Windows pour lancer VHR Dashboard et son serveur embarqué.

Étapes d'installation :

1) Cliquez sur « Télécharger l'installateur » ci-dessous pour récupérer VHR.Dashboard.Setup.1.0.3.exe.
2) Lancez le fichier téléchargé, confirmez les avertissements SmartScreen (Informations complémentaires → Exécuter quand même) et suivez l'assistant (Next → Install → Finish).
3) Un raccourci « VHR Dashboard Pro » est déposé sur votre bureau et dans le menu Démarrer.
4) Ouvrez ce raccourci pour démarrer l'application. Le navigateur s'ouvrira sur http://localhost:3000/vhr-dashboard-pro.html.

Alerte SmartScreen / antivirus :

Les navigateurs ou Windows peuvent afficher un avertissement sur l'installateur VHR.Dashboard.Setup.1.0.3.exe car il est récent. Si vous faites confiance à VHR Dashboard, cliquez sur :
• Dans le navigateur : Conserver puis Conserver quand même (ou équivalent).
• Dans Windows SmartScreen : Informations complémentaires → Exécuter quand même.

Authentification requise

Une fois le dashboard ouvert, vous devez vous authentifier pour que la période d'essai de 7 jours commence.

Vous pouvez :

  • Créer un compte avec votre email
  • Vous connecter si vous avez déjà un compte

Conseil : Gardez votre session ouverte pour que le décompte des 7 jours soit actif.

Prérequis :

  • Serveur local en cours d'exécution (port 3000)
  • Navigateur web moderne (Chrome, Edge, Firefox)
  • Cookies activés
